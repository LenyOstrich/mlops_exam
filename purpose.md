### Постановка цели

Рассмотрим задачу прогнозирования спроса на товары для управления складскими запасами магазина. Для решения используются три основные сущности: товар, склад и заказ. Бизнес-метрика — доля заказов, выполненных без дефицита товара на складе.

Бизнес-требование заключается в том, чтобы максимизировать долю заказов, которые могут быть полностью выполнены за счёт имеющихся запасов. На языке ML-проектирования эта задача формулируется как задача регрессии: по историческим данным о продажах необходимо прогнозировать спрос на каждый товар на заданный период вперёд.

Целевая переменная — количество единиц товара, которое будет заказано в будущем периоде. Для оценки качества модели используются метрики MAE (средняя абсолютная ошибка) и RMSE (корень из среднеквадратичной ошибки), показывающие точность прогнозирования спроса. Чем меньше ошибка прогноза, тем точнее рассчитываются складские запасы и тем выше доля заказов, выполненных без дефицита товара.
